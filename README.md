# Jogo de perguntas e respostas em C

É um jogo de perguntas e respostas sobre os conceitos abordados na disciplina de Algoritmo implementado em linguagem C.


## 🎮 Funcionalidades

- Divisão por Níveis: O jogo possui 5 níveis de dificuldade, com perguntas específicas para cada nível.
- A cada nível, uma pergunta aleatória é selecionada, sem repetições dentro do mesmo nível.
- Perguntas e alternativas organizadas por nível, com 3 questões por nível e 4 alternativas em cada uma.
- O jogador avança de nível ao acertar a resposta. Uma resposta errada encerra o jogo.
- Registro das Respostas: As respostas do jogador são armazenadas para exibição posterior.
- Ao final do jogo, é exibido um resumo com:

Perguntas respondidas

Alternativas corretas

Respostas escolhidas pelo jogador
  

## 📦 Pré-requisitos

- Compilador C (GCC recomendado)
- Sistema operacional Linux/Windows/macOS

- ## 🚀 Como Executar

- Clone o repositório ou copie o código fonte

- Compile o programa:
- gcc -o Perguntas.exe Perguntas.c
- Para exucutar : 
  .\Perguntas.exe
